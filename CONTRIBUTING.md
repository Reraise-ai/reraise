# Contributing

Reraise is an open project. It gets better with every person who brings a card. You do not
need to write code to take part.

## Four ways in

1. **Get your number.** Every trading partner gets a running number:
   [reraise.ai/#number](https://reraise.ai/#number) or [reraise.ai/trade/](https://reraise.ai/trade/).
2. **Bring in a card.** One thing you found, with its source behind it, on the
   [exchange](https://reraise.ai/trade/).
3. **Bring your field.** You know a subject better than we do. Tell us which on
   [reraise.ai](https://reraise.ai/#join).
4. **Open an issue or a discussion here.** For a mistake, a gap or an unclear sentence in the
   card format or the documents.

## What a good card is

- **One statement.** If you need "and", it is probably two cards.
- **Its source.** A proven or said card names where it comes from: a document, an address,
  or another card. Copies of the same story count as one source, so name the origin, not the
  place you saw it repeated.
- **The right layer.** `evidenced` if it traces to a source or an original, `said` if
  somebody claimed it, `experience` if you lived through it. What you believe is not a layer;
  it stays on your device.
- **Public only.** Bring in only what is publicly findable and contains no private data.

The rules of the exchange are at [reraise.ai/trading-rules/](https://reraise.ai/trading-rules/).

## Proposing a change to the card format

1. Open an issue that describes the problem first: which card cannot be written today, or
   which rule is unclear. Include an example card.
2. If the change is agreed, open a pull request against
   [docs/card-format.md](docs/card-format.md).
3. The format only adds: a change must not make an existing valid card invalid. Identifiers
   that are part of the stored format (field names, the `wb:` URI prefix, folder names) are
   not renamed.

## Licence of contributions

Contributions to this repository are accepted under the Apache License 2.0
([LICENSE](LICENSE)). Sign off every commit with the
[Developer Certificate of Origin](https://developercertificate.org/):

```
git commit -s
```

This adds a line like `Signed-off-by: Your Name <your address>` to the commit message.
Pull requests without a sign-off on every commit cannot be merged. See
[LICENSING.md](LICENSING.md).

## Conduct

Argue with cards, not with people. Name incentives, not villains.
